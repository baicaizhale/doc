# 命令全表

以下是 LiteMotto 及其别名 `/lm` 的完整指令。

| 命令 | 参数 | 描述 | 示例 |
| :--- | :--- | :--- | :--- |
| `/litemotto` | `gen` | 立即为自己生成一条格言 | `/lm gen` |
| `/litemotto` | `debug` | 开启/关闭个人调试模式 | `/lm debug` |
| `/litemotto` | `reload` | 重载配置文件 (即使有自动重载，也可手动触发) | `/lm reload` |
| `/litemotto` | `update` | 手动检查 GitHub 上的新版本 | `/lm update` |

## Tab 自动补全
插件支持 Tab 补全。输入 `/litemotto ` 后按 Tab 键，会自动列出所有可用的子命令。
