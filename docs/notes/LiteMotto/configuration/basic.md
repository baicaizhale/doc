# 基础配置

本节介绍 `config.yml` 中最常用的基础设置。

## 核心项

### `version`
- **类型**: 字符串
- **说明**: 内部版本标识。**请勿修改**，否则可能导致配置更新器无法正常工作。

### `api-provider`
- **类型**: 枚举 (`cloudflare`, `siliconflow`)
- **说明**: 指定格言生成的后台。
- **默认**: `cloudflare`

### `prompt`
- **类型**: 字符串
- **说明**: 给 AI 的指令。你可以通过修改它来改变格言的风格（如：幽默、文言文、鲁迅风格等）。
- **示例**: `"请用文言文写一句关于人生的格言"`

### `prefix`
- **类型**: 字符串
- **说明**: 游戏内消息的前缀。
- **支持**: `&` 颜色代码。
- **默认**: `"§bLiteMotto §7> §f"`

## 消息自定义

### `messages.motto-generation-failed`
- **说明**: 当 API 请求失败时，发送给触发生成（如玩家加入）的普通玩家的消息。
- **建议**: 设置为温馨的提示，避免引起恐慌。
